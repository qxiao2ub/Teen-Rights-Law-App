# Security Policy

## Reporting a vulnerability

Do not open a public issue containing exploit details, credentials, private user information, or information that could endanger a teenager.

For a real deployment, configure a monitored private security-reporting address in this file before launch. Until then, use a private repository report or contact the repository owner through an established private channel.

## Prototype limitations

- No authentication or database is included.
- Session data is not designed for sensitive information.
- Moderation is rule-based and incomplete.
- Browser text-to-speech depends on the user's browser.
- The legal topic library is educational and not jurisdiction-verified.

A production release requires threat modeling, dependency scanning, logging, rate limiting, privacy review, content review, and an incident-response process.
