# Contributing

Thank you for helping improve this educational prototype.

## Before contributing

- Do not submit private information about a teenager or any other person.
- Do not submit confidential, regulated, or restricted data.
- Do not add jurisdiction-specific legal claims without an official source and qualified review.
- Do not weaken emergency, exploitation, privacy, or moderation safeguards.

## Code contributions

1. Create a branch.
2. Make a focused change.
3. Run `python -m unittest discover -s tests -v`.
4. Run `python -m py_compile streamlit_app.py src/legal_engine.py`.
5. Explain the safety and privacy impact in the pull request.

## Content contributions

Each legal-content change should include:

- Jurisdiction.
- Official source.
- Effective date.
- Plain-language explanation.
- Reviewer name or review status.
- Expiration or next-review date.

Unreviewed content should remain clearly labeled as draft and should not be presented as verified law.
